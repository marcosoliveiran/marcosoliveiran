# Pasta de imagens do vídeo "Creep"

Coloque aqui os arquivos abaixo, com exatamente estes nomes. Se algum faltar, o
vídeo mostra um quadro de reserva com o nome do arquivo, então dá para ir
montando aos poucos. Use fotos de imprensa, capas oficiais e imagens que você
tenha direito de usar. De preferência com até 1600 px de largura.

| Arquivo | O que é |
|---|---|
| `thom-jovem.jpg` | Thom Yorke no início dos anos 90 |
| `jonny.jpg` | Jonny Greenwood com guitarra |
| `banda-1993.jpg` | Radiohead em 1993 |
| `capa-pablo-honey.jpg` | Capa do álbum Pablo Honey (1993) |
| `capa-single-creep.jpg` | Capa do single Creep (1992) |
| `capa-ok-computer.jpg` | Capa do OK Computer (1997) |
| `capa-air-that-i-breathe.jpg` | Capa do single The Air That I Breathe (The Hollies) |
| `logo-billboard.png` | Logo da Billboard |
| `logo-spotify.png` | Logo do Spotify |
| `logo-bbc.png` | Logo da BBC |
| `plateia.jpg` | Foto genérica de plateia em show |

`thom-atual.jpg` do roteiro original não é usado nesta versão.

O vídeo cortado, `fala.mp4`, é gerado por `npm run cortar` e não vai para o Git.
